## 詳細な説明 (最大 4000 文字)

```
「四字熟語道場」は、漢字四文字の熟語をゲーム感覚で学べる、和モダンなクイズアプリです。
中学生レベルの定番から、漢検1級相当の難問まで、400問以上の四字熟語を収録しています。
段位昇段・星獲得・図鑑収集といった、続けたくなる仕掛けが満載。

■ こんな人におすすめ
・国語力を磨きたい中高生・受験生
・漢検2級〜1級を目指している方
・ビジネスで使える表現の引き出しを増やしたい社会人
・通勤や休憩時間のスキマ学習に最適なクイズを探している方
・日本語・漢字が好きな学習者

■ 主な機能

【ステージモード】
5ステージ × 8ラウンド = 40ラウンド、全400問。
各ラウンドは10問の4択クイズ。10問正解で☆5、2問間違えるごとに☆1つ減ります。
前のラウンドをクリアすると次がアンロック。難易度はステージが進むほど高くなります。

【マラソンモード】
ランダム50問に挑戦。正解率から「推定上位◯%」が算出されます。
自己ベストはローカルに保存され、ベスト更新時には派手な演出も。

【クロスワードモード】
2つの四字熟語が漢字を共有する4×4のパズル。
ドラッグ&ドロップで漢字を空きマスに埋めてください。1セッション5問。

【4種類の出題形式】
・ふつう … 漢字と読みから意味を選ぶ
・穴埋め … 伏せられた漢字を選ぶ
・読みなし … ふりがなを頼らず漢字だけで意味を選ぶ
・意味先出し … 意味から該当する四字熟語を当てる

出題形式は1問ごとにランダム。同じ熟語でも違う角度から学べます。

【ヒントアイテム】
・50:50 … 誤答を2つ消す
・ふりがな … 読みを公開
・時間+ … 制限時間に+10秒
正解時に一定確率でドロップします。

【段位とレベル】
・正解数に応じて段位が昇格 (白帯→青帯→…→名人)
・5問正解ごとにレベルアップ、レベル帯ごとにバッジ色が変化
・レベルアップ時は紙吹雪と「おめでとうございます!」モーダル

【図鑑】
全収録熟語の一覧ビュー。1回でも正解した熟語は「獲得済み」に。
タップで意味・読み・イラスト (一部) が確認できます。

【本日の四字熟語】
日替わりで一つの熟語を紹介。時間帯に応じた挨拶も表示。

■ その他のこだわり
・Noto Serif JP / Noto Sans JP フォント同梱で起動時文字化けなし
・BGM と効果音付き (ミュート可)
・正解時に紙吹雪の祝福演出
・和モダンで落ち着いた配色 (朱・墨・藍・若葉・山吹)
・各熟語にイラストを順次追加中

■ データと安全性
・クイズの進捗はすべて端末内のみに保存
・個人情報の収集・送信は一切ありません
・広告配信は Google AdMob を使用 (プライバシーポリシーは開発者連絡先に記載)

スキマ時間の学び直しから、本気の漢検対策まで。
一日一問、四字熟語の道を極めてみませんか。
```
