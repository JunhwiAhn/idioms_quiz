## ASO 전략 메모

Play 검색은 **앱 이름 > 간단한 설명 > 자세한 설명** 순으로 가중치를 둡니다.
출시 노트(What's new)는 색인 대상이 아니므로 키워드를 넣어도 검색 노출에 기여하지 않습니다.

### 재포지셔닝 (2차 개정)

1차 개정에서 앱 이름에 `스페인어 단어장` 류의 일반 키워드를 넣어 가장 큰 구멍은 메웠습니다.
남은 문제는 **DELE 편중**입니다. 개정 전 기준 언어당 `DELE` 8~9회 대 여행·회화 2~3회였습니다.

`DELE`는 시험 응시자만 검색하는 좁은 키워드입니다. 반면 `스페인어 공부`, `여행 스페인어`,
`aprender espanhol`, `espanhol para viagem` 은 모수가 훨씬 큽니다. 특히 브라질에서는
DELE 인지도 자체가 낮아 DELE를 앞세우면 대부분의 검색에서 아예 걸리지 않습니다.

그래서 **여행·일상 회화를 앞에, DELE는 신뢰 근거로 뒤에** 배치했습니다. DELE를 빼지는 않습니다 —
어휘 선정 기준을 설명해 주고, 경쟁 앱과 차별화하는 근거이기 때문입니다.

타깃 키워드 (1순위가 앞, DELE는 보조):

| 언어 | 1순위 | 2순위 |
|---|---|---|
| ko | 스페인어 공부, 여행 스페인어, 스페인어 회화 | 스페인어 단어장, DELE, 델레, 스페인어 초보 |
| en | learn Spanish, Spanish for travel | Spanish vocabulary, Spanish phrases, DELE, beginners |
| ja | スペイン語 学習, 旅行 スペイン語, スペイン語 会話 | 単語帳, DELE, スペイン語検定, 初心者 |
| pt | aprender espanhol, espanhol para viagem | vocabulário de espanhol, espanhol básico, DELE |

수록 어휘는 실제 데이터 기준 **1,257개** (A1 489 / A2 466 / B1 302) 이므로 "1,250개 이상" 표기는 정확합니다.

브랜드명을 앞에 두면 검색 가중치가 가장 높은 자리를 브랜드가 차지합니다. 현재 설치 46명이라
브랜드 손실은 미미하지만, 최종 판단은 필요합니다.
