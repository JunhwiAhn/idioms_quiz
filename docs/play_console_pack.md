## 4. 詳細な説明 (4000 文字以内)

```
「四字熟語道場」は、漢字四文字の熟語を段位制のゲーム感覚で学べる、和モダンな学習アプリです。
中学生レベルの定番から、漢検準1級・1級相当の難問まで、400問以上の四字熟語を収録。
段位昇段・星獲得・図鑑収集といった、続けたくなる仕掛けで語彙力を鍛えます。
通勤や休憩時間のスキマ学習から、本格的な漢検対策まで、一日一問、四字熟語の道を極めてみませんか。

■ 主な機能

【ステージモード — 基礎から段階的に】
5ステージ × 8ラウンド = 全40ラウンド、400問の4択クイズ。
各ラウンドは10問構成で、10問正解で☆5、2問間違えるごとに☆が1つ減る評価方式。
前のラウンドをクリアすると次がアンロックされ、ステージが進むほど難易度が上がります。
自分のペースで基礎から着実にステップアップしたい方に最適です。

【道場破りモード — 実力を測るマラソン挑戦】
ランダム50問のマラソン形式。正解率から「推定上位◯%」が算出され、全国順位の目安として可視化されます。
自己ベストはローカル端末に保存され、ベスト更新時には特別な演出でモチベーションアップ。
「どれだけ身についたか」を定期的に測りたい方にぴったりです。

【クロスワードモード — パズルで発想力を鍛える】
2つの四字熟語が漢字を共有する4×4のクロスワードパズル。
ドラッグ&ドロップで空きマスに漢字を埋めて、2つの熟語を同時に完成させます。
1セッション5問構成。熟語同士のつながりを意識することで、記憶が立体的になります。

【4種類の出題形式でマルチアングル学習】
・ふつう    … 漢字と読みから意味を選ぶ
・穴埋め    … 伏せられた漢字を選ぶ
・読みなし  … ふりがなを頼らず漢字だけで意味を選ぶ
・意味先出し … 意味から該当する四字熟語を当てる

出題形式は1問ごとにランダムに切り替わるので、同じ熟語でも違う角度から繰り返し学べます。

【段位制で学習を継続】
正解数の累計に応じて、白帯 → 黄帯 → 青帯 → 茶帯 → 黒帯 → …… → 名人へと段位が昇格。
5問正解ごとにレベルアップし、レベル帯ごとにバッジの色が変化します。
昇段・レベルアップ時には紙吹雪の演出と「おめでとうございます!」のモーダルで達成感を演出。
ゲーム要素を「学習の継続モチベーション」として設計しています。

【図鑑 — 自分だけの熟語コレクション】
全収録熟語の一覧ビュー。1回でも正解した熟語は「獲得済み」として記録されます。
タップで意味・読み・用例・イラスト (一部熟語) を確認可能。
覚えた熟語が増えていく視覚的な達成感が、継続学習を後押しします。

【本日の四字熟語】
日替わりで1つの熟語を紹介。時間帯に応じた挨拶とともに、今日覚える1語をさり気なくお届けします。

■ 学習に役立つポイント

・問題数が豊富: 400問以上を4種類の出題形式で、実質的に多面的な演習が可能
・反復に強い設計: 間違えた熟語は図鑑で確認、出題形式を変えて自然に復習
・オフライン完全対応: 電車の中や Wi-Fi のない環境でも、インターネット接続なしでいつでも学習可能
・和モダンな UI: 朱・墨・藍・若葉・山吹を基調とした、目に優しく落ち着いた配色
・Noto Serif JP / Noto Sans JP フォント同梱で、端末によらず美しい字形で表示
・BGM と効果音で没入感 (ミュート可、学習環境に合わせて調整可能)

■ こんな方におすすめ

・漢検準1級・1級を目指して語彙を増やしたい方
・国語力・語彙力を磨きたい中高生・大学生・受験生
・ビジネス文書やスピーチで使える表現の引き出しを増やしたい社会人
・日本語・漢字・四字熟語が好きな学習者、教養を深めたい大人
・スキマ時間にゲーム感覚で学べる教育アプリを探している方

■ 学習モード解説 (使い分けの目安)

・初めての方    → まずは「ステージモード」ステージ1から順にクリア
・腕試ししたい方 → 「道場破り」で全国の推定順位をチェック
・気分転換に    → 「クロスワード」で漢字の共通点を探してひらめき学習
・復習したい方  → 「図鑑」から獲得済み熟語を見直し

■ その他のこだわり

・データはすべて端末内 (SharedPreferences) にのみ保存
・ユーザー登録・ログイン不要、個人情報の収集・送信は一切なし
・フィードバックは外部の Google フォームで受付 (任意、匿名投稿可)
・継続的に熟語のイラスト・解説を追加中

日々の学びを「道」にする、静かで奥深い四字熟語の世界。
今日から「四字熟語道場」で、あなたの語彙力を段位に変えていきませんか。
```

## 9. プライバシーポリシー URL

Play Console 必須項目。`docs/privacy_policy.md` を Web 上で公開して URL を取得します。

### 推奨: GitHub Pages で無料公開 (最もシンプル)

1. GitHub リポジトリ (`idioms_quiz`) を開く
2. **Settings** → 左メニュー **Pages**
3. **Source** を `Deploy from a branch` に設定
4. **Branch** を `main` / フォルダを `/docs` に設定し **Save**
5. 数分待つと以下のような URL で公開されます:
   ```
   https://junhwiahn.github.io/idioms_quiz/privacy_policy
   ```
   (`.md` はリポジトリ名や Jekyll 設定により `.html` に変換されます。`docs/privacy_policy.md` をそのまま Markdown で置いておけば、GitHub Pages の標準テーマで HTML レンダリングされます。)
6. 公開 URL を Play Console の「プライバシーポリシー」欄に貼り付け

### 代替案

| 方法 | 概要 | 備考 |
|---|---|---|
| GitHub raw | `https://raw.githubusercontent.com/<user>/idioms_quiz/main/docs/privacy_policy.md` | プレーンテキスト表示。許容はされるが見栄えが悪い |
| Notion 公開ページ | `docs/privacy_policy.md` の内容を Notion ページに貼り付け、`Share → Publish to web` | 見栄え良好。URL が長め |
| Netlify Drop | `privacy_policy.html` に変換し drag & drop | 独自ドメインも可能 |

> 初回は **GitHub Pages** を強く推奨します (コード管理と同じリポジトリで完結)。
