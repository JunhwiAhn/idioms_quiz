## 5. 데이터 세이프티 (Data Safety)

Play Console → 「앱 콘텐츠」 → 「데이터 보안」. **AdMob SDK가 수집하는 항목을 신고해야 합니다.**

### 5.1 수집/공유 여부

| 설문 | 답변 |
|---|---|
| 앱이 사용자 또는 기기 데이터를 수집하거나 공유하는가? | **`예`** |

### 5.2 수집 데이터 유형 (AdMob 기준)

| 카테고리 | 항목 | 수집 | 공유 | 목적 |
|---|---|---|---|---|
| 위치 | 대략적인 위치 (IP 기반) | 예 | 예 | 광고 |
| 앱 활동 | 앱 상호작용 | 예 | 예 | 광고, 분석 |
| 앱 정보 및 성능 | 진단 | 예 | 예 | 분석 |
| 기기 또는 기타 ID | 광고 ID | 예 | 예 | 광고 |

- 처리 방식: **전송 중 암호화됨** — `예`
- 삭제 요청: 학습 데이터는 기기 내 저장 / 앱 삭제로 전부 삭제. 광고 ID는 기기 설정에서 재설정 가능.
- 각 항목 "필수 수집"으로 표시 (광고는 앱 기능의 일부).

> 정확한 최신 가이드는 AdMob 공식 문서 "Play 데이터 보안 섹션 → Google Mobile Ads SDK" 페이지를 제출 직전에 재확인할 것. SDK 버전에 따라 신고 권장 항목이 갱신됩니다.

### 5.3 데이터 삭제 설명란 문안

```
학습 진행도·점수·설정은 모두 사용자 기기 내부에만 저장되며, 앱을 삭제하면 완전히 삭제됩니다. 광고 게재를 위해 Google AdMob이 광고 ID 등 기기 정보를 수집할 수 있으며, 이는 Google의 정책에 따라 관리됩니다. 사용자는 기기 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다.
```

## 6. 광고 관련 필수 작업 (제출 전)

1. **AdMob 콘솔 → 개인 정보 보호 및 메시지(Privacy & messaging)** 에서 **GDPR 메시지(유럽 규정 메시지)를 생성·게시**할 것. 앱에 UMP 동의 코드는 이미 구현되어 있으나(`lib/data/ad_service_mobile.dart`), 콘솔에 메시지가 게시되어 있지 않으면 EEA에서 동의 양식이 뜨지 않음.
   - 경로: https://apps.admob.com → 좌측 「개인 정보 보호 및 메시지」 → 「유럽 규정」 메시지 만들기 → 대상 앱 선택 → 게시
   - 미국 주(州) 규정 메시지도 함께 게시 권장 (같은 화면에서 설정)
2. AdMob 콘솔에 앱을 스토어 등록정보와 연결(게시 후).
3. `app-ads.txt`: [docs/app-ads.txt](app-ads.txt) 파일 생성 완료 (`google.com, pub-1633662132825683, DIRECT, f08c47fec0942fa0`).
   - **주의**: app-ads.txt 표준은 파일이 **도메인 루트**에 있어야 함. GitHub Pages 프로젝트 사이트(`junhwiahn.github.io/idioms_quiz/`)에서는 루트(`junhwiahn.github.io/app-ads.txt`)에 놓을 수 없으므로, ①`junhwiahn.github.io`라는 이름의 사용자 사이트 리포지토리를 만들어 그 루트에 app-ads.txt를 두거나 ②커스텀 도메인을 쓰는 방법이 있음. app-ads.txt는 **권장 사항(미게시 시에도 광고 송출은 됨)**이므로 초기 출시 후에 처리해도 무방.
   - AdMob 콘솔에서 개발자 웹사이트로 등록한 URL 기준으로 크롤링됨.
4. Play Console 「앱 콘텐츠」 → 「광고」 질문에 **`예, 광고 포함`** 으로 답변.
