# 四字熟語 100 イラスト生成プロンプト集

このファイルは **ChatGPT Plus (GPT-4o / gpt-image-1) で四字熟語 100 枚のイラストを半手動バッチ生成する** ためのものです。

---

## 使い方

1. ChatGPT で新規チャットを開く
2. 下の **「共通スタイル」** を 1 回だけ貼る (「了解」が返ってきたら次へ)
3. **バッチ 1 〜 20** を 1 つずつ別メッセージとして貼る (1 バッチ = 5 枚)
   - 途中で生成ペースが遅くなったら、別チャットに移ってもう一度スタイルを貼ればリセット可能
   - レート制限に当たったら数時間空ける
4. 生成画像を右クリック保存 → `assets/images/{ファイル名}.png` に配置
5. すべて揃ったら「画像を組み込んで」とエンジニア (Claude Code) に伝える

> **ファイル名について**: Flutter は Unicode ファイル名を扱えるので、漢字そのまま `一期一会.png` で保存して OK。ChatGPT 側で「`一期一会.png` として書き出して」と指示すれば ZIP DL も可能です。

---

## 共通スタイル (最初に 1 回だけ貼る)

```
これからお願いする 100 枚のイラストはすべて下記スタイルで統一してください。

- モダンなフラットイラスト、和モダンテイスト
- 1:1 正方形、中央構図、余白広め
- パレット: 生成り (#FAF6F2) の背景に、墨 (#2C2A29) / 朱 (#B03A2E) / 藍 (#4A6FA5) / 若葉 (#8CB369) / 山吹 (#E6A817) の 3〜4 色をポイント使い
- 軽い和紙テクスチャ、墨の筆跡アクセント可
- 画像内に文字・漢字・アルファベット・ハンコ類は一切入れない
- 四字熟語の「意味」をひと目でわかる 1 シーンで表現する (直訳でなく比喩でも可)
- 人物はシルエットか簡素な描写、顔の詳細は省く

了解いただけたら「了解」とだけ返してください。そのあと私がバッチ 1 から順に投げます。
```

4. 換骨奪胎 — 古典的な器に新しい色や文様を重ね塗りして生まれ変わる過程の連続コマ。 → 換骨奪胎.png
5. 用意周到 — 出発前の机に整然と並ぶ地図・水・道具・メモ。隙のない準備の静物画。 → 用意周到.png

## 画像が揃ったあとの組み込み手順 (メモ)

1. 全 100 枚を `assets/images/` に保存
2. `pubspec.yaml` の `assets:` に `- assets/images/` を追加
3. `lib/models/idiom.dart` に `imagePath` フィールドを追加
4. `assets/data/idioms.json` 各エントリに `"imagePath": "assets/images/一期一会.png"` を追記
5. `QuizScreen` の問題表示部に画像カードを配置

この作業は Claude Code に「画像を組み込んで」と依頼すれば自動化可能です。

## トラブル時

- **レート制限に当たった**: 数時間空けるか別アカウントに切替。24h 空ければだいたいリセット。
- **スタイルがぶれる**: そのバッチ冒頭に再度「生成り背景・和モダン・文字なし」と 1 行だけリマインドを添える。
- **文字が入ってしまう**: 「絶対に文字・漢字・ロゴを入れない」と強調し、出た場合はそのコマだけ再生成依頼。
- **漢字ファイル名が NG なサービス**: ローマ字代替名 (例: `ichigoichie.png`) で保存しても OK。あとで組み込み側で対応します。
