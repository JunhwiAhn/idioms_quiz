# プライバシーポリシー — 四字熟語道場

**最終更新日: 2026年4月21日**

本プライバシーポリシーは、Junhwi Ahn (以下「当方」) が提供するモバイルアプリケーション「四字熟語道場」(以下「本アプリ」) における利用者情報の取り扱いについて定めるものです。

## 1. 収集する情報

### 1.1 当方が直接収集する情報
本アプリは、**ユーザーの個人を特定できる情報を一切収集・送信しません**。以下のデータはすべて**ユーザー端末のローカル領域 (SharedPreferences) にのみ保存**され、外部サーバーへ送信されることはありません。

- クイズの回答履歴・正解数・段位・レベル
- マスター済みの四字熟語リスト
- マラソンモードの自己ベスト・直近スコア
- ステージごとの星獲得状況
- ヒントアイテムの保有数
- 音量・ミュート設定

### 1.2 広告配信のために収集される情報
本アプリは広告配信サービスとして **Google AdMob** を使用しています。AdMob は広告のパーソナライズや不正防止のため、以下の情報を自動的に取得する場合があります:

- 広告 ID (端末固有の識別子、再設定・オプトアウト可能)
- 端末情報 (OSバージョン、モデル、言語設定)
- 大まかな位置情報 (IP アドレスから推定される国・地域レベル)
- アプリ利用状況 (広告の表示回数、クリック等)

AdMob のデータ取り扱いの詳細については Google のプライバシーポリシーをご確認ください。
https://policies.google.com/privacy

## 2. 情報の利用目的

- クイズの進行状況・スコアをユーザー端末上で保存・表示するため
- AdMob を通じた広告配信の最適化のため (Google が実施)

## 3. 第三者提供

当方はユーザーの個人情報を**第三者に販売・提供しません**。広告配信のために Google に自動送信される情報については、上記 1.2 および Google のポリシーをご参照ください。

## 4. 広告識別子のオプトアウト

広告のパーソナライズを拒否したい場合は、端末の設定から以下の操作が可能です:

- **Android**: 設定 → Google → 広告 → 広告 ID を削除 / パーソナライズされた広告をオプトアウト
- **iOS**: 設定 → プライバシーとセキュリティ → トラッキング → 「App からのトラッキング要求を許可」をオフ

## 5. データの保持と削除

本アプリが保存するすべてのローカルデータは、**アプリをアンインストールすることで完全に削除されます**。当方側にはバックアップや記録は残りません。

## 6. 未成年者について

本アプリは全年齢を対象としていますが、13 歳未満の児童に特化したサービスではありません。AdMob は 13 歳未満の児童向けコンテンツに該当する場合、Google の子ども向けポリシーに準拠した広告のみ配信されます。

## 7. ポリシーの変更

本プライバシーポリシーは、法令の変更やサービス内容の変更に応じて改訂される場合があります。重要な変更がある場合は、アプリ内またはストアの説明欄にて通知します。
