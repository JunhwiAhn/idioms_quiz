# 흘려듣기 영상용 이미지

여기에 아래 파일명 그대로 넣어주세요. 렌더러가 파일명으로 찾아 씁니다.
**없는 파일은 자동으로 브랜드 색 배경으로 대체**되므로, 만들어지는 대로 하나씩 넣으셔도 됩니다.

모든 파일은 `.png` 또는 `.jpg` 둘 다 인식합니다.

| 파일명 | 크기 | 용도 |
|---|---|---|
| `thumbnail.png` | 1280×720 | 유튜브 썸네일 (영상에는 안 들어감, 업로드 시 별도 등록) |
